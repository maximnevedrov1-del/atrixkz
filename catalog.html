Какой пылесос Atrix подходит для МРТ?

Для зоны магнита МРТ выпускается единственная немагнитная модель — Atrix Omega Green Supreme MRI (артикул VACOS220MRI). Она исключает «штуцер-эффект» и повреждение томографа.

Что означает сертификат Class H по IEC/EN 60335-2-69?

Это высший класс удержания опасной пыли (асбест, свинец, силикат, плесень). Пылесосы Atrix Omega Class H14 с ULPA-фильтром улавливают 99,999 % частиц размером 0,12 мкм и юридически подтверждают защиту по охране труда.
