Часто задаваемые вопросы

Что такое пылесос CLASS H?

Пылесос CLASS H — высший класс по IEC/EN 60335-2-69 для работы с канцерогенной пылью. Требования: ULPA фильтрация 99.995% при 1 мкм, Immediate Containment (замена без контакта), сертификат TÜV/SGS. Применяется для асбеста, свинца, кварцевой пыли, радиоактивных частиц.

Когда обязателен CLASS H пылесос?

CLASS H обязателен: асбест (OSHA 29 CFR 1910.1001), свинец (OSHA 1910.1025), кварцевая пыль (MSHA 30 CFR 72), ядерные объекты (МАГАТЭ GSR Part 3). В Казахстане — требование HSE аудитов ТШО, NCOC, КПО, Kazzinc, ArcelorMittal.
