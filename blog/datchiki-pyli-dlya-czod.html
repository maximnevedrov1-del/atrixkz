Датчики пыли для ЦОД: типы, установка, нормы

Atrix Kazakhstan · 5 августа 2026 г.

Датчик пыли в ЦОД — это не роскошь, а инструмент предиктивного обслуживания. Он предупреждает о росте загрязнения до того, как пыль успеет забить радиаторы и фильтры. Вместо календарной уборки "раз в квартал" вы переходите на уборку по факту — когда датчик говорит, что пора.

Типы датчиков пыли

1. Оптические счётчики частиц (Particle Counters)

Золотой стандарт. Лазерный луч + фотодетектор. Измеряют количество частиц разного размера в реальном времени.

Плюсы: точность, разделение по размерам, непрерывный мониторинг. Минусы: цена, необходимость калибровки.

2. Оптические датчики плотности пыли (PM sensors)

Упрощённая версия: измеряют общую плотность пыли (PM2.5, PM10) без разделения по размерам. Как в бытовых очистителях воздуха.

Плюсы: компактность, низкая цена, простота. Минусы: меньшая точность, нет детализации.

3. Датчики перепада давления на фильтрах

Косвенный метод: измеряют сопротивление воздуха на фильтре HVAC. Рост перепада = фильтр забит = в зале больше пыли.

Плюсы: дёшево, надёжно, интегрируется с BMS. Минусы: не измеряет пыль напрямую, только тренд.

4. Электростатические датчики

Измеряют заряд пылевых частиц. Используются в промышленности для контроля горючей пыли.

Нормы и пороги срабатывания

Для серверной класса ISO 8:

  • Норма: ≤100 000 000 частиц 0,5 мкм/м³
  • Предупреждение: >150 000 000 — усилить фильтрацию, проверить герметизацию
  • Тревога: >300 000 000 — экстренная уборка, проверить HVAC

Для более чистых зон пороги ниже пропорционально.

Интеграция с системой мониторинга

Современные датчики поддерживают:

  • Modbus TCP/RTU — интеграция с BMS/DCIM
  • SNMP — для систем сетевого мониторинга
  • 4–20 мА / 0–10 В — аналоговые интерфейсы
  • HTTP API — для облачных платформ
