Что такое Data Center Valley Kazakhstan {#chto-takoe}

Data Center Valley — это масштабный национальный проект Казахстана по созданию кластера дата-центров мирового уровня. Проект реализуется в рамках программы цифровой трансформации страны и направлен на превращение Казахстана в ключевой узел цифровой инфраструктуры Евразии.

Концепция проекта:

  • Создание выделенной территории с развитой инфраструктурой для размещения ЦОД
  • Привлечение глобальных технологических компаний
  • Формирование полноценной экосистемы: ЦОД + R&D + образование + резиденты
  • Использование возобновляемых источников энергии
  • Применение передовых технологий охлаждения (liquid cooling, free cooling)

Почему это важно для поставщиков оборудования:

Каждый ЦОД — это сотни и тысячи единиц оборудования для поддержания чистоты: ESD-пылесосы, системы фильтрации, оборудование для мониторинга качества воздуха, средства для подготовки помещений. Data Center Valley создаст спрос на тысячи единиц специализированного оборудования в ближайшие 3–5 лет.

Экосистема ЦОД Казахстана: Kaspi, Kazakhtelecom, Akashi {#ekosistema}

Data Center Valley — не единственный проект. В Казахстане уже действует и строится экосистема ЦОД, создающая стабильный спрос на оборудование.

Kaspi — 2 собственных ЦОД

Kaspi, крупнейший фintech-холдинг Казахстана, построил 2 собственных дата-центра для обеспечения работы своих сервисов:

  • Требования: ESD-защита, HEPA H13+, мониторинг качества воздуха
  • Масштаб: десятки серверных стоек
  • Особенность: финансовый сектор — повышенные требования к безопасности

Kazakhtelecom — ЦОД в Косшы

Национальный телеком-оператор инвестирует в строительство современного ЦОД в посёлке Косшы:

  • Мощность: десятки МВт
  • Класс: Tier III+
  • Требования: Полный набор cleanroom-оборудования, ESD, мониторинг

Akashi — первый Tier IV ЦОД

Akashi строит первый в Казахстане Tier IV дата-центр — класс с наивысшей отказоустойчивостью:

  • Tier IV — uptime 99.995%, полная избыточность всех систем
  • Требования к cleanroom: ISO 14644-1 Class 6–7, ULPA H14
  • Значение: устанавливает новый стандарт для региона

Freedom Cloud — облачная платформа

Freedom Finance запустил Freedom Cloud — облачную платформу для бизнеса:

  • Собственная инфраструктура ЦОД
  • Требования к чистоте помещений серверных зон
  • Необходимость регулярной уборки с ESD-защитой

Требования ANSI/TIA-942 к оборудованию чистых помещений {#tia-942}

Стандарт ANSI/TIA-942 — главный мировой стандарт для дата-центров. Он определяет требования к помещениям, инфраструктуре и, в том числе, к чистоте.

Требования к оборудованию для строительной уборки:

  • Мощность всасывания: 800+ AW — для тяжёлого строительного мусора
  • Фильтрация: HEPA H13 минимум — для предотвращения повторного загрязнения
  • Ёмкость контейнера: 30+ литров — для сбора большого объёма мусора
  • Маневренность: колёса, компактные габариты — для работы в стеснённых условиях стройки
