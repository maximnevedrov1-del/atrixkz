Kazakhaltyn — золотодобывающие предприятия

На золотодобывающих и золотоизвлекательных фабриках используется цианид натрия для гидрометаллургии. Пыль содержит золото, серебро и цианидные соединения — все они CLASS H по OSHA 29 CFR 1910.1000 (Toxic and Hazardous Substances).

Технические точки применения CLASS H

  • Мельничный зал (ball mill) — металлическая и горная пыль, CLASS H
  • Сорбционные колонны — цианидная пыль при обслуживании, CLASS H
  • Плавильный цех (пробирная лаборатория) — золото, серебро пыль, CLASS H
  • Электролизный цех — медная пыль при чистке ванн, CLASS H
